# Logo venue

Taruh logo tiap venue di folder ini dengan nama persis seperti berikut
(dipakai langsung oleh `community.html`):

| File                   | Venue                              | Instagram            |
|------------------------|------------------------------------|----------------------|
| `basecamp.jpg`         | Basecamp Board Game Cafe & Store   | @basecamp.boardgame  |
| `tabletoys.jpg`        | Tabletoys Board Game               | @tabletoys           |
| `grand-colosseum.jpg`  | Grand Colosseum Board Game         | @grandcolosseum      |
| `tsumo-mahjong.jpg`    | Tsumo Mahjong (Malang)             | @tsumomahjong        |

Cara ambil: buka profil Instagram venue, simpan foto profilnya, crop jadi
kotak (1:1), lalu simpan dengan nama di atas. Ukuran 200x200 px sudah cukup.

Selama file belum ada, kartu venue otomatis menampilkan monogram inisial
(BC / TT / GC / TM) sebagai pengganti — jadi halaman tetap rapi.

Catatan: logo adalah milik masing-masing venue. Sebaiknya minta izin atau
minta file logo resmi langsung ke mereka sebelum dipakai di situs.
